# 深圳大学计算机科学课程作业与学习资料

本仓库整理深圳大学（SZU）计算机科学本科阶段的课程资料，内容包括课程作业、实验报告、课程项目、教师课件、试卷、试题及参考答案。目录沿用原有年级和课程结构，便于按学期与课程查找。

## 仓库内容

- 课程作业与实验报告
- 课程设计与项目源代码
- 课程汇报与演示文稿
- 教师课件与课程讲义
- 试卷、试题与参考答案
- 复习资料与课程分享材料

## 年级目录

- [大一课程](./大一课程/)：高等数学、线性代数、大学物理、计算机导论、计算机系统、数字电路等。
- [大二](./大二/)：数据结构、离散数学、概率论、Java、机器学习、算法设计、计算机网络、计算机系统等。
- [大三](./大三/)：Web 编程、数据库系统、计算机图形学、编译原理、操作系统、大模型技术及应用等。
- [大四](./大四/)：计算机视觉、自然语言处理、智能网络与计算等。
- [义往情深](./义往情深/)：课程分享、复习资料与朋辈学习材料。

## 文件范围

仓库保留与课程学习直接相关的代码和文档，不收录压缩包、视频、安装包、可执行程序、依赖目录、构建缓存、大型数据集、模型权重、数据库、凭据及私人材料。部分较大的课件通过 Git LFS 保存。
